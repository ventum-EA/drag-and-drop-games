# drag-and-drop-games
A fun and interactive Unity 2D drag-and-drop game designed for children!
Players must drag cars and drop them into randomly placed parking spaces on the map — but be careful! Avoid obstacles like clouds, planes, and bombs that can destroy the car you’re holding.
Earn points for each correctly placed car and for how long you survive without crashing.
## Gameplay Overview
Goal: Drag and drop each randomly placed car into the correct parking space.
Avoid: Flying obstacles (clouds, planes, bombs) that can destroy your car.
Scoring:
- Points for each correctly placed car
- Bonus for time survived
Lose: When your held car is destroyed by an obstacle.
